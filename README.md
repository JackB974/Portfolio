# Portfolio

A bilingual, static portfolio with a short profile, skills, selected projects, education, and experience. The French page is `index.html`; the English page is `en.html`. Shared styles live in `style.css`.

## Preview

Open `index.html` locally or serve this folder with any static-file server. The published site is [GitHub Pages](https://jackb974.github.io/Portfolio/).

## Update the content

- Edit the French and English pages together so their claims stay aligned.
- Keep the pages factual and concise. The projects are described without public app or repository links; Course listings describe learning, not automatically earned certifications.
- Older page URLs are small redirects to the new site, so existing bookmarks continue to work.
- The site intentionally has no photo, résumé, phone number, or email address. The public GitHub profile is not linked.
- Before adding personal information, remember that GitHub Pages is public and repository history can retain removed files.

## Publishing

This repository currently publishes through GitHub Pages. Push changes to the configured publishing branch, then verify both language pages and the legacy redirects at the live URL. No private server is required.
